# BADHack1_ResearchBridge

A shared repository for building **ResearchBridge**: a tool that connects researchers with industry partners, corporations, and startups.

## Purpose
This repo is the team hub to keep:
- shared planning notes
- UI/UX artifacts
- implementation code
- workstream-specific documentation

## Team Workstreams
- **Story & user path exploration** → `/story`
- **Industry partner interface (UI/UX + implementation)** → `/industry-partner-ui`
- **Research summarization tool (researcher-relevant summaries)** → `/research-summarizer`
- **Cross-team notes and coordination** → `/shared-notes`

## Suggested Collaboration Flow
1. Add notes and decisions to `/shared-notes`.
2. Build each workstream in its own folder.
3. Keep links to shared assets (for example, Miro board) in `/shared-notes`.
4. Use pull requests for changes so all teammates can review.
